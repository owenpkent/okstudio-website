## What it does

A managed voice dictation app for Windows. Press a global hotkey from any app, speak, and get cleaned-up text auto-pasted into the active window. No API keys, no configuration, no training period.

## Features

- **Press, speak, paste**: global hotkey from any app, transcript lands in the active window.
- **AI cleanup**: Claude-powered grammar, punctuation, and formatting on top of Deepgram nova-2 transcription.
- **Agentic writing mode**: describe what you want and get finished content back, not just dictation.
- **Native Windows audio**: Tauri 2 desktop app, WASAPI capture, lightweight Rust backend.
- **EV code-signed**: installs cleanly on managed Windows machines.

## Built for

Power typists (writers, customer service, professionals), accessibility users with RSI or limited keyboard use, and anyone who's tired of fighting Windows Speech Recognition.
